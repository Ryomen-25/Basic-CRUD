# Basic-CRUD API

A clean, modular RESTful API built with **FastAPI**. This project demonstrates the implementation of fundamental CRUD (Create, Read, Update, Delete) operations, utilizing **Pydantic** for robust data validation and an organized project structure suitable for scalable application development.

## 🚀 Features

* **RESTful Design**: Standard HTTP methods (GET, POST, PUT, DELETE) for resource management.
* **Data Validation**: Uses Pydantic models to ensure strict data integrity and type safety.
* **Modular Architecture**: Organized structure separating routes, schemas, and logic for better maintainability.
* **Auto-Documentation**: Comes with Interactive Swagger UI and ReDoc out-of-the-box (accessible via `/docs`).
* **Asynchronous Support**: Built to handle requests efficiently using FastAPI's asynchronous capabilities.

## 🛠 Tech Stack

* **Framework**: [FastAPI](https://fastapi.tiangolo.com/)
* **Data Validation**: [Pydantic](https://docs.pydantic.dev/)
* **Language**: Python 3.10+
* **ASGI Server**: Uvicorn
